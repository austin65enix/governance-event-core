# Scope and Non-Claims

## In scope

- canonical governance event shape;
- source-to-canonical mapping invariants;
- semantic qualification;
- source identity preservation;
- negative authority preservation;
- open vocabulary extension points.

## Out of scope

- governed-run identity;
- authorization state machines;
- state-transition validation;
- durable closeout;
- runtime execution;
- persistence;
- database binding;
- product-specific profiles.

A conformant governance event is not proof that an execution was authorized. Semantic qualification is not authorization.
